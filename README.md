# 📝 Simple Note App

A lightweight web application designed for quick personal note-taking. It helps you keep track of your daily thoughts, tasks, and ideas in one place.

---

## What Does This App Do?

- **Write Notes:** You can enter a title and a description to quickly save a new note.
- **View Your List:** All saved notes appear on the screen neatly as organized cards.
- **Edit Notes:** You can change the title or details of any note whenever you want.
- **Remove Notes:** You can delete notes you no longer need.
- **Instant Updates:** Changes happen right on the screen without reloading the page.
- **Permanent Storage:** Your notes stay saved in a data file on the server, so you do not lose them when you refresh or close the browser.
